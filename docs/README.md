# The documents

**One row per repository document, saying what it is for.** This page is the
index and is in no index itself; the front page, [`../README.md`](../README.md),
is the entry point and is what every page here assumes has been read. The
bootcamp artifact has its own [chapter index](../bootcamp/README.md#chapters).

| document | what it settles |
| --- | --- |
| [`../README.md`](../README.md) | the repository's entry point, purpose and scope |
| [`maintenance.md`](maintenance.md) | **start here to maintain this tree** — where to start, what this repository is responsible for, what is reserved to a person, and what is currently owed elsewhere |
| [`discussion.md`](discussion.md) | the standing channel — what is being said to another tool, staged here for a person to carry. Nothing in it is sent by a program |

Every document in this directory is authored prose, initially mostly written
by AI agents. **Nothing here is generated by a script**, so there is no page
that a run rewrites and none that can be regenerated if it is lost.
